# 从数据到图表的选择参考

先用用户的问题决定图形，再用字段结构验证选择。若多个图形都合理，优先信息密度适中、可比较、可解释且能在静态 Figure 中稳定复现的方案。

## 常见映射

| 数据问题 | 常见字段结构 | 优先图形 | 注意事项 |
| --- | --- | --- | --- |
| 随时间变化 | 日期/年份 + 一个或多个数值 | 折线、阶梯线、面积 | 时间排序；注明缺口，不把缺失点默认为零 |
| 类别之间比较 | 类别 + 数值 | 排序条形、点图、区间图 | 类别顺序明确；类别过多时聚合长尾 |
| 两个变量关系 | 两个连续变量，可选分组 | 散点、趋势线、分面 | 不把相关性写成因果；重叠点可透明或聚合 |
| 分布和异常 | 一个连续变量，可选类别 | 直方图、箱线图、ECDF | 说明 bin 或分位数规则；样本少时避免过度平滑 |
| 构成和占比 | 总量 + 部分，或各部分之和 | 100% 堆叠、堆叠面积、少量条形 | 部分必须有共同分母；避免不必要的饼图 |
| 多变量矩阵 | 多个数值字段 | 小 multiples、热图、散点矩阵 | 只展示与问题相关的字段，保持色阶和单位一致 |

## 数据处理底线

- 日期解析、类别排序、单位换算和聚合规则必须确定且写入代码；不要依赖本地化环境或当前时间。
- 缺失值、重复值、异常值和过滤条件必须在 `data_note` 或交付说明中可追溯。
- 百分比、率和指数要保留分母或基准说明；不要仅把小数格式化成百分号而隐去定义。
- 误差线、置信区间和分组统计应沿用真实计算；不能用视觉装饰替代不确定性。
- 颜色、线型和标记应有稳定的语义映射；同一项目内相同类别尽量保持一致。

## 可编辑属性边界

适合放入 schema 的包括尺寸、留白、背景、字体、字号、颜色、线宽、透明度、轴范围、刻度、网格、图例位置和注释位置。数据筛选、模型选择、聚合窗口、统计检验和阈值属于分析逻辑，默认保留在代码中；只有用户明确要交互调整时才暴露，并为其定义清晰的范围和单位。
