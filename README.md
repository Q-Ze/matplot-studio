# Matplot Studio

Matplot Studio 是一个面向 Python 用户与科研人员的本地 Web 应用：代码是事实来源，右侧属性面板负责快速调整常用 Matplotlib 参数，画布随修改重新渲染。

## 已实现

- 项目 / plot 左侧导航；支持导入或删除项目、向指定项目导入单个 `plot.py` 或递归扫描文件夹、删除单个 plot；一个 plot 对应一个 `Figure` 与一个 `plot.py`
- Python 代码编辑、自动保存、`Ctrl/⌘ + Enter` 手动运行
- 从规范代码自动读取属性，并将修改写回 `PLOT_SETTINGS`
- 属性添加、删除、类型校验和 revision 冲突保护
- SVG 实时预览以及缩放、平移、适应窗口
- PNG、SVG、PDF 图片导出（保持画布尺寸或紧裁切），同边界模式的 600 DPI PNG 一键复制，以及 CSV、JSON 数据导出
- 独立 Python 子进程渲染、超时终止和 traceback 展示
- 可新建空项目，也可导入符合契约的项目或独立 `plot.py`
- 科研拼图：项目内多图网格排版、跨行跨列、拖动换位、毫米尺寸与标注，保存布局及矢量 PDF / SVG、高清 PNG 导出

## 科研拼图

选择项目中的一张图表，点击顶部功能栏的 **科研拼图**。添加项目内的图表，选择行列位置；可拖动网格中的子图换位，或设置“跨行 / 跨列”组成不等大小的面板。每张拼图最多 16 张子图，网格最多 6 × 6；“按顺序平铺”会重置跨格并按列表顺序排放。

点击 **导入示意图** 可加入手绘草图、照片或其他图片，支持 PNG、JPG、WebP、单页 TIFF、SVG 和单页 PDF（最多 20 MiB；位图最多 2500 万像素）。图片保留透明背景及原始纵横比，并按照片方向信息自动转正；动画及多页文件需先导出为单张图片或单页 PDF。PDF 需未加密；SVG 需为具有画布尺寸的静态、自包含图片，外部图片需先嵌入，特殊字体建议转为路径。网格已满时导入会自动增加一行，最多 6 行、16 张子图。

导入图片保存在项目的 `composition-images/<id>/` 中，可从子图来源下拉框再次选择，与 Matplotlib 图表混合排版。图片的原有留白会保留，“原图边界”选项只影响 Matplotlib 图表。移除子图或删除拼图不会删除可复用的图片素材。SVG / PDF 素材存储为矢量 PDF，编辑画布使用缩略图，尺寸匹配依据原始画布比例。导出 PDF / SVG 时保留素材和图表中的矢量内容；素材中已有的位图仍为位图，放大不会增加其原始清晰度。PNG 导出及剪贴板复制仍按所选 DPI 生成位图。

也可以点击 **粘贴子图** 从剪贴板读取图片，或点击拼图画布后按 **Ctrl/⌘ + V**。粘贴图片沿用导入图片的大小限制，并保存为可复用的项目素材；在名称、标注等输入框内粘贴文字时，不会触发图片导入。浏览器不支持或未允许剪贴板读取时，可使用快捷键粘贴或“导入示意图”。

点击 **复制拼图**，会先保存当前布局，再按分辨率下拉框所选的 **300 / 600 DPI** 生成完整 PNG 并写入剪贴板，无需先生成预览。支持的浏览器还会附带 HTML 图片的毫米尺寸信息，供 Word / PowerPoint 等软件使用；最终粘贴尺寸取决于目标软件对剪贴板格式的支持。复制功能需要本机地址或 HTTPS，以及浏览器的剪贴板写入权限。

画布宽高、外边距和格间距以毫米为单位，提供 85 mm 单栏和 180 mm 双栏宽度快捷设置。子图保持纵横比，支持保留原图画布或裁去外部留白。标注支持 `a`、`A`、`(a)`、自定义英文 / 数字标注及隐藏；标注覆盖在实际子图图片左上角，不单独占用顶部空间；标注字号以最终输出的 pt 为准，原图中的字号随子图整体缩放。

**编辑布局** 会自动显示真实子图及其比例，无需先生成整张预览。点击 **按原图比例适配高度**，可在保留当前宽度、网格和跨格设置的前提下，按子图比例计算合适的画布高度。图像始终等比例缩放；不同纵横比的子图仍可能产生留白。

点击 **生成预览** 查看实际输出，使用 **编辑布局 / 实际预览** 随时切换；未改动布局时可复用已有预览，修改后重新生成。原图更新后，点击 **刷新原图** 更新编辑画布。点击 **保存拼图** 保存布局，再次打开编辑器可从“已保存的拼图”切换。导出按钮会先保存当前布局，再生成 PDF、SVG 或 300 / 600 DPI PNG。PDF / SVG 保留原图中的矢量内容；原图中的位图仍为位图。PNG 最多 8000 万像素。

布局存放于项目下的 `compositions/<id>.json`，引用同项目图表，不复制或改写原图。修改原图后重新生成预览或导出即可更新；删除原图后需为相应子图重新选择来源。未保存的拼图在关闭前会提示。导出和预览使用最新的已保存原图，布局中的空格会保留为留白。

## 启动

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e .
python -m matplot_studio
```

随后打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。也可以通过环境变量指定位置：

```bash
MATPLOT_STUDIO_PORT=8080 MATPLOT_STUDIO_WORKSPACE=/path/to/workspace python -m matplot_studio
```

当前版本定位为本机单用户工具，会执行工作区内受信任的 Python 代码，不应直接暴露到公网。

`workspace/` 是仅供本机使用的运行目录，并已从 Git 中排除。项目代码、内嵌数据、渲染图片和原始绘图脚本不会随本仓库发布；需要共享图表时，请先单独审查其代码和数据。

## Plot 目录与代码契约

```text
workspace/
└── project-id/
    ├── project.json
    └── plots/
        └── plot-id/
            └── plot.py
```

每个 `plot.py` 必须自包含，并定义：

- `PLOT_META`：名称、版本和数据来源说明
- `PLOT_SCHEMA`：属性面板可添加或编辑的属性目录
- `PLOT_SETTINGS`：当前启用的属性值，也是属性面板唯一会自动改写的代码块
- `prepare_data()`：同文件内的数据准备或确定性演示数据
- `render(data, settings)`：返回且只返回一个 Matplotlib `Figure`

应用负责渲染和导出，因此 `plot.py` 不应调用 `show()`、`savefig()` 或 `close()`。完整格式见 `.codex/skills/matplot-studio-converter/references/plot-contract.md`。

项目导入时可选择包含上述结构的 ZIP，或直接选择项目根文件夹。ZIP 可以包含项目所需的二进制资源；文件夹导入用于 UTF-8 文本项目。导入前会校验 `project.json`、目录结构和每个 `plot.py` 的代码契约，重名项目会自动获得新的项目编号。

也可以在左侧某个现有项目上选择“导入图表”：直接选择一个规范 `plot.py`，或选择任意文件夹并递归查找其中所有名为 `plot.py` 的文件。整批文件会先完成契约与 ID 冲突校验，再一次性加入项目。

## 转换原始绘图代码

项目内提供了两个 skills：

- `$matplot-studio-converter`：将已有 Matplotlib 绘图脚本转换为规范 `plot.py`。
- `$matplot-studio-generator`：从用户授权的原始数据出发，完成数据处理、图表设计，并直接生成规范 `plot.py` 或完整项目。

两者都会把渲染所需数据和处理逻辑放进同一个 `plot.py`，执行静态校验和 smoke 渲染；缺少真实依赖或数据时，应生成确定性的演示数据并明确标注，而不是留下无法运行的本地 import。
